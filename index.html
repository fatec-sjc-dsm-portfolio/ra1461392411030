API · PROJETO ACADÊMICO
5º semestre · 2026 · Xertica

⚖️ Themis

Plataforma inteligente de análise jurídica em nuvem

🏢
Parceria

Xertica - FATEC Profº Jessen Vidal

🎯
Objetivo

Analisar petições iniciais, identificar precedentes relevantes e gerar resumos e minutas para apoio à decisão jurídica

⚠️
Problema

Profissionais do Direito precisam analisar grandes volumes de petições e precedentes, localizar informações relevantes e preparar documentos de apoio em pouco tempo, tornando a pesquisa manual demorada e sujeita a inconsistências.

✅
Solução

Uma plataforma em nuvem que combina aplicativo mobile, API e base de precedentes para organizar a análise jurídica, apresentar resultados relevantes e apoiar a elaboração de resumos e minutas.

🛠 Stack Tecnológica

Flutter Python FastAPI MongoDB Docker Docker Swarm Figma

💡 Principais Contribuições

🔧 Desenvolvimento do aplicativo mobile e da experiência do usuário
🌐 Estruturação do fluxo de análise jurídica com IA e NLP
📊 Organização dos resultados com precedentes, resumo e aplicabilidade
🚨 Modelagem dos fluxos para advogado, juiz e julgador
🔗 Integração entre app, API e base de precedentes
📱 Prototipação de interfaces e documentação do projeto

Hard skills adquiridas

Desenvolvimento de aplicativo mobile com Flutter, integração entre cliente e API, modelagem de fluxos de uso, prototipação no Figma, organização de dados e compreensão de soluções com IA e NLP.

Soft skills exercitadas

Trabalho em equipe, comunicação com diferentes perfis de usuário, organização de tarefas, colaboração na tomada de decisões e apresentação de soluções.
